description: Check the admin and console pages and run the browser flows
---
With the server running on the test school (`bash tools/dev-reset.sh` in the background), run `node tools/check-pages.mjs --changed` for the pages your change reaches (`--full` for every page at four widths in light and dark, as CI does; `--scans all` adds the layout scans; `--popups` opens each page's drawers and dialogs) and `ONLY="text" node tools/e2e-flows.mjs` for the flows it touches. The dev servers answer on `localhost` (`ADMIN=http://localhost:5173 CONSOLE=http://localhost:5174`); point `ADMIN=http://localhost:4000 CONSOLE=http://localhost:4000/console` at the server's built apps (after `pnpm build`) to check them as Render serves them. Fix the cause of every failure (a flow that only fails because an earlier run changed the data is not a bug: reset and re-run). Report what is green and what the scripts cannot judge (real devices, the owner's taste).
