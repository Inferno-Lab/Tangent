# Runbooks

What to do, step by step, when something goes wrong or a school asks for something unusual. Each names the console page
or command to use and what to check after. Keep them true: when a screen changes, change its runbook in the same commit.

| When | Runbook |
| --- | --- |
| A school's data is wrong or lost and must go back to an earlier point | [restore-a-school.md](restore-a-school.md) |
| A key or password may have leaked, or is due for a change | [rotate-a-secret.md](rotate-a-secret.md) |
| Texts, emails or payments stop going through | [switch-a-provider.md](switch-a-provider.md) |
| A school must run on another server or in another region | [move-a-school.md](move-a-school.md) |
| A family or staff member asks for a copy, a correction or deletion of their data | [data-rights-request.md](data-rights-request.md) |
| Personal data may have reached someone it should not | [breach.md](breach.md) |
